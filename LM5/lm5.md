# Learning Module 5


## Pipeline Examples


Get-Date | Select-Object Day, Month, Year


Get-Process | Select-Object ProcessName, Id


## Properties Selected


For Get-Date, I selected the Day, Month, and Year properties.


For Get-Process, I selected the ProcessName and Id properties.


## What I Learned


I learned how to use the PowerShell pipeline to pass objects from one command to another. I also learned how to use Select-Object to display specific properties from the objects returned by a command.
